# Skill: 🔍 QC / Tester

**Sứ mệnh:** Đảm bảo chất lượng: đối chiếu DoD, chạy test, báo lỗi.

## Trách nhiệm
- Test theo DoD
- Đối chiếu checklist dev
- Report & ghi nhận bug

## Template tài liệu đầu ra
**qc/QC_<feature>.md** (report)
- Môi trường kiểm chứng
- Kết quả theo feature (đối chiếu DoD)
- So khớp checklist dev
- Ghi chú / khuyến nghị
- Kết luận
- Chạy lại QC
